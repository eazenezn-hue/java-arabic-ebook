# كتاب Java للمبتدئين

تطبيق ويب عربي تفاعلي يساعد المبتدئين على بدء رحلة تعلم Java من خلال كتاب قابل للقراءة والبحث والتصدير بصيغة PDF.

## المزايا

- واجهة عربية كاملة باتجاه RTL وخط Cairo.
- فهرس تفاعلي مع بحث داخل الأقسام.
- وضع فاتح وداكن مع حفظ التفضيل.
- أمثلة Java باتجاه LTR مع إبراز الصياغة وزر نسخ.
- فصل أول مكتمل بالعربية يشرح Java وJDK وJRE وJVM وبرنامج Hello World.
- تصدير الكتاب إلى PDF مع غلاف وفواصل صفحات وتنسيقات طباعة.
- تصميم متجاوب للكمبيوتر والهاتف.

## التشغيل محلياً

```bash
pnpm install
PORT=5000 BASE_PATH=/ pnpm --filter @workspace/java-arabic-ebook run dev
```

افتح التطبيق من خلال معاينة Replit أو على العنوان المحلي الذي يظهره Vite.

## بنية المشروع

- `artifacts/java-arabic-ebook` — تطبيق القراءة الرئيسي.
- `artifacts/api-server` — خادم API المشترك في مساحة العمل.
- `lib` — المكتبات المشتركة وتعريفات API.
